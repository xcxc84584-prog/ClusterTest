# Global Property Registry

| Property | Owner | Default |
| --- | --- | --- |
| Version | LinkCore | 由 LinkCore/release.json 發佈（目前 OCDA-P6） |
| Language | LanguageUI | zh-Hant |
| SyntaxHighlight | HighlighterUI | true |
| HighlightShortcut | HighlighterUI | Ctrl+Shift+H |
| HighlightPerformance | HighlighterUI | false |

All runtime properties must be registered via URU. No credentials are stored.
