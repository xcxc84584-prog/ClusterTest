# ClusterTest

OCDA-based rebuild of ClusterOpt. Reference: https://github.com/xcxc84584-prog/ClusterOpt

**v0.0.1 Patch +1:** LinkCore foundation and a minimal independent editor/file-loading prototype. This is **not yet feature-equivalent** to ClusterOpt. Original repository remains unchanged.

Run via any static HTTP server (for example `python -m http.server 8000`), then open `http://localhost:8000/`. Run tests with `node --test tests/*.test.mjs` (Node 20+).
